# 🧠 What is Artificial Neural Network?

> Artificial Neural Networks (ANNs) are computational models inspired by the human brain. They learn patterns from data by adjusting weights through training and are widely used for classification, regression, prediction, and intelligent decision-making.

# 🧩 Main Concepts

| Concept | Description |
|---------|-------------|
| 🧠 Neuron | Basic processing unit |
| ⚖️ Weights | Learn importance of features |
| ➕ Bias | Helps shift activation |
| 🔥 Activation Function | Introduces non-linearity |
| ➡️ Forward Propagation | Generates prediction |
| 🔄 Backpropagation | Updates weights |
| 📉 Loss Function | Measures prediction error |
| 🚀 Optimizer | Minimizes loss |
| 🎯 Epoch | One complete training cycle |
| 📦 Batch | Subset of training data |

# 🔥 Activation Functions

<p align="center">

| Function | Usage |
|----------|--------|
| Sigmoid | Binary Classification |
| ReLU | Hidden Layers |
| Leaky ReLU | Prevent Dead Neurons |
| Tanh | Centered Output |
| Softmax | Multi-class Classification |
