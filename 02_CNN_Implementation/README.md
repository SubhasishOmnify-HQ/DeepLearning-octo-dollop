# 🖼️ What is CNN?

> **Convolutional Neural Network (CNN)** is a specialized Deep Learning algorithm designed to process image and video data. It automatically extracts important features such as edges, textures, shapes, and objects, making it the foundation of modern Computer Vision applications.

# 🧩 Main Concepts

| Concept | Description |
|---------|-------------|
| 🖼️ Image | Input data |
| 🔍 Convolution | Feature Extraction |
| 🎛️ Filter (Kernel) | Detect patterns |
| 📍 Stride | Sliding step size |
| 🧱 Padding | Preserve image size |
| 🔥 ReLU | Activation Function |
| 🏊 Max Pooling | Reduce dimensions |
| 📄 Flatten | Convert to 1D vector |
| 🧠 Dense Layer | Final prediction |
| 🎯 Softmax | Multi-class output |

---

# 🔍 CNN Layer Overview

| Layer | Purpose |
|--------|---------|
| 📷 Input | Receive image |
| 🔍 Convolution | Extract features |
| 🔥 ReLU | Add non-linearity |
| 🏊 Pooling | Down-sampling |
| 📄 Flatten | Convert matrix to vector |
| 🧠 Dense | Classification |
| 🎯 Output | Final prediction |
