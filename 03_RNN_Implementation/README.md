# 🔄 What is RNN?

> **Recurrent Neural Network (RNN)** is a Deep Learning model designed for sequential data. Unlike traditional neural networks, RNNs remember previous information using hidden states, making them ideal for Natural Language Processing (NLP), speech recognition, and time-series forecasting.

# 🧩 Main Concepts

| Concept | Description |
|---------|-------------|
| 🔢 Sequential Data | Ordered data |
| 🧠 Hidden State | Memory of previous inputs |
| 🔁 Recurrence | Reuse previous information |
| ⏳ Time Step | One sequence position |
| 📤 Output Sequence | Prediction |
| 🔄 BPTT | Backpropagation Through Time |
| 🔥 Activation | Tanh / ReLU |
| 🎯 Softmax | Classification Output |
| 📈 Sequence Learning | Learn temporal patterns |
| 📝 Context Memory | Previous knowledge |

# 🔁 Sequence Processing

| Stage | Purpose |
|--------|---------|
| 📥 Input Sequence | Receive sequential data |
| 🧠 Hidden State | Store memory |
| 🔄 Recurrent Layer | Process previous output |
| 📤 Output Layer | Predict next value |
| 🎯 Prediction | Final output |
