# 💬 What is Natural Language Processing?

> **Natural Language Processing (NLP)** is a branch of Artificial Intelligence that enables computers to understand, process, analyze, and generate human language. It combines **Linguistics, Machine Learning, and Deep Learning** to build intelligent language-based applications.

# 🧩 Main Concepts

| Concept | Description |
|---------|-------------|
| 📝 Corpus | Collection of text documents |
| 🔤 Tokenization | Split text into words/sentences |
| 🚫 Stopwords | Remove common words |
| 🌱 Stemming | Reduce words to root form |
| 🌿 Lemmatization | Convert to dictionary form |
| 📖 POS Tagging | Identify grammatical roles |
| 🏷️ Named Entity Recognition | Detect names, places, organizations |
| 🎯 Text Classification | Categorize text |
| 📚 Language Model | Predict next word |
| 💬 Text Generation | Generate human-like text |
